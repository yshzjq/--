# AI 사용 안내, 기록

이 과제에서는 **개념 질문과 자신이 작성한 코드의 디버깅**에 AI를 사용할 수 있습니다. 필수문제와 선택 심화문제에 같은 기준을 적용합니다.

## 사용할 수 있는 질문

- JSON Schema의 타입 검증과 출처 ID 검사는 무엇이 다른가요?
- Reasoning 프롬프팅과 Self-Consistency의 적용 상황을 비교해 주세요.
- 제가 작성한 이 반복문은 마지막 실패 뒤에도 대기합니다. 어떤 조건을 확인해야 하는지 설명해 주세요.
- 이 코드는 제가 작성했습니다. 예상 결과와 실제 오류를 보고 원인을 설명해 주세요.

디버깅을 요청할 때에는 직접 작성한 코드의 필요한 부분, 기대한 동작, 실제 오류, 이미 확인한 사항을 함께 제시하세요. 설명을 이해한 뒤 직접 수정하고 해당 단계 검사를 다시 실행합니다.

## 사용할 수 없는 요청

- 과제 전체 또는 아직 작성하지 않은 TODO 함수를 완성해 달라는 요청
- baseline/reasoning/대상별 프롬프트를 대신 작성해 달라는 요청
- 다른 과제라는 이름으로 같은 요구사항의 완성 코드를 생성하는 요청
- 실행하지 않은 결과, 비용, 캐시 적중 수치를 만들어 달라는 요청
- 심화문제 설계를 대신 작성해 달라는 요청

AI 답변에 완성 풀이가 포함되었다면 그대로 제출하지 말고, 필요한 개념 설명으로 질문 범위를 좁히세요. API 키나 실제 개인정보는 대화에 넣지 않습니다. 과제 담당자에게 질문할 때에도 현재 단계와 관찰한 오류를 함께 전달하면 도움이 됩니다.

## 사용 기록

AI를 사용하지 않았다면 아래에 `사용하지 않음`이라고 적으세요. 사용했다면 질문별로 행을 추가합니다. API 키와 개인정보를 제외하고, 질문 원문과 받은 설명의 요지를 남깁니다.

- 사용 여부: 사용함
- 사용 도구, 모델: OpenAI Codex 데스크톱 앱의 대화형 AI 어시스턴트(GPT-6 기반). 정확한 세부 모델 식별자는 확인하지 못함.
- 기록 범위: 정책 프롬프트, 답변 검증과 수정, 티켓 조회, 오류 화면 입력에 활용한 도움. 질문은 원문의 의미를 유지하며 말투·맞춤법을 정리했고, 같은 주제의 반복 질문과 긴 코드는 묶거나 생략했다. 아래 내용은 질문 원문 그대로의 인용이 아니다.
- 활용 내용: 개념 설명, 직접 작성한 프롬프트·코드 검토, 수정 조건·함수 호출 예시, 정책의 일부 수정 표현, 이유·한계 주석 예문과 오류별 수정 안내 문자열을 제공받았다.
- 작성 구분: 구현과 프롬프트는 사용자가 작성·수정하고 실행했다. 기존 기록에 따르면 AI가 요청받은 TODO 두 개를 주석으로 추가한 이력이 있다. AI가 이 사용 기록도 작성·갱신했으며, 이번 갱신에서는 구현 코드를 수정하지 않았다.
- 과제에서 실제 호출한 `gpt-5.6-luna`는 프로그램의 호출 대상이며, 코딩 도움을 받은 대화 모델과 구분한다.

## 확인한 결과와 남은 범위

- **저장된 검사 결과:** 정책 1/1, 답변 검증과 수정 18/18, 티켓 조회 5/5, 이미지 입력 1/1 통과. 이번 기록 갱신에서는 검사를 새로 실행하지 않았다.
- **실제 실행:** 정책 네 건, 답변 한 건, 티켓 조회 한 건, 이미지 한 건의 live 결과 파일을 확인했다. 답변은 Python 3.12와 policy-python 출처를 제시했다. 티켓 조회는 IT-1043의 해결 상태와 policy-incident 출처를 제시했다. 이미지는 401 표시를 설명하고 인증·권한 확인을 안내했다.
- **결과의 한계:** fixture의 오류 복구 성공과 실제 모델 실행을 구분했다. 이미지 답변 중 화면에 자격 증명이 없다는 표현은 여기서 별도 이미지 대조를 하지 않았으므로 정확성을 확정하지 않았다. 일부 사례의 성공을 전체 정책 준수나 품질 보장으로 확대하지 않는다.
- **미완료:** 현재 코드에는 호출 재시도, 사용량·비용, 전체 연결 및 선택 심화의 미구현 부분이 남아 있다. 전체 검사, 최종 26개 사례 비교와 제출 완료로 기록하지 않는다.
